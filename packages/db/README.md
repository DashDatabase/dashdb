# @dashdb/db

Drizzle ORM schema and client for DashDB's own Postgres metadata database. This is not the user
databases DashDB connects to.

- `src/schema.ts`: table definitions. Change these, then run `pnpm db:generate`.
- `migrations/`: SQL generated by drizzle-kit. Commit these.
- `createDb(url)` → `{ db, close }`.

```sh
docker compose up -d postgres
pnpm db:generate   # schema.ts -> migrations/*.sql
pnpm db:migrate    # apply to DATABASE_URL (defaults to the compose Postgres)
pnpm test:db       # integration tests (*.db.test.ts); `pnpm test` skips them
```
