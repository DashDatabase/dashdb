Every team has the same two tools for its database schema, and they don't talk to each other.
There is the diagram: a whiteboard photo, a dbdiagram.io link, a Figma file someone made once.
And there is the migration: SQL written by hand, or generated by an ORM, reviewed by whoever is
around, and run in production with fingers crossed.

DashDB puts them in one place. You change the diagram; DashDB writes the migration and tells
you what it will do to a production database before you run it.

## The loop

1. **Import** the schema you have: SQL, a Prisma schema, DBML, or a live Postgres or MySQL
   database, through a read-only query you run yourself.
2. **Save a baseline**, a snapshot of what is in production.
3. **Change the design** on the canvas or in the Code tab, which stays in sync both ways.
4. **Generate the migration**: up and down SQL, or a Prisma Migrate or drizzle-kit migration,
   with the changes highlighted on the diagram.
5. **Read the safety review.** Twelve rules check for the operations that hurt in production:
   table rewrites, blocking index builds, `NOT NULL` scans, renames that break running code,
   and steps that lose data. Each finding comes with a safer way to make the same change.

## Local-first, on purpose

The editor runs entirely in your browser. Projects are saved on your device, and DashDB never
connects to your database: importing a live schema means pasting the result of a query you ran
in your own client. There is no account to create, and nothing to upload.

That is a privacy decision, but also a practical one. It works against databases behind a VPN,
in a locked-down environment, or on a plane.

## What you get today

- A fast canvas that stays smooth with hundreds of tables, with automatic layout.
- Two-way code editing in SQL, Prisma and DBML.
- Export to SQL, Prisma, Drizzle, DBML, PNG, SVG and Mermaid.
- Migrations with confirmed renames, dependency-aware ordering and transaction handling that
  knows `CREATE INDEX CONCURRENTLY` can't run inside one.
- [Twelve ready-made templates](/templates) and [free converters](/tools) between formats.

It is free, and it is open source under the AGPL-3.0.
