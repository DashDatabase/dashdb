## Polish and accessibility

<time dateTime="2026-10-31">October 31, 2026</time>

- Keyboard shortcuts for every action, listed in a cheat sheet (press <kbd>?</kbd>).
- A four-step tour on a ready-made SaaS starter project for first-time visitors.
- Screen-reader announcements for edits and undo, arrow-key navigation in the sidebar, and
  visible focus everywhere.
- The editor loads about ten times less JavaScript on first visit.
- If something goes wrong, the error screen offers to export your project first.
- Fixed: typing in the Code tab could trigger canvas shortcuts.

## Import and export

<time dateTime="2026-10-31">October 31, 2026</time>

- Paste SQL with automatic dialect detection, or upload `.sql`, `.prisma`, `.dbml` and
  `.dashdb.json` files.
- Import from a live Postgres or MySQL database with a single read-only query you run yourself.
- Export PNG or SVG images, SQL, Prisma, Drizzle, DBML, a backup file, or a Mermaid ER diagram.

## Migration panel

<time dateTime="2026-10-31">October 31, 2026</time>

- Generate migrations as SQL, Prisma or Drizzle from your edits since the last baseline.
- A safety review flags table rewrites, long locks and breaking renames, with a safer
  alternative for each.
- See the change on the canvas: added, changed and removed tables are highlighted.

## Code tab

<time dateTime="2026-10-31">October 31, 2026</time>

- Edit your schema as SQL, Prisma, Drizzle or DBML, with changes synced to the diagram both ways.

## Diagram canvas

<time dateTime="2026-10-31">October 31, 2026</time>

- Draw tables and relationships, with one-click auto-arrange for large schemas.
- Projects save automatically in your browser, with undo, redo and baselines.

## The schema engine

<time dateTime="2026-10-30">October 30, 2026</time>

- One schema model behind everything, with parsers and serializers for SQL, Prisma, Drizzle and
  DBML.
- A diff engine that detects renames instead of dropping and re-adding.
- Twelve migration safety rules for Postgres and MySQL.
